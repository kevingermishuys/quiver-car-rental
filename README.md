# Quiver Car Rental

Toyota Fortuner 4x4 rentals based in Swakopmund, Namibia.

Live site: https://quiver-car-rental.pages.dev/

## About this repo

This is a static mirror of the deployed site, recovered from the live
Cloudflare Pages deployment on 2026-09-01. The original Cloudflare Pages
project (`quiver-car-rental`) was deployed via direct upload with no
connected Git repository, so this snapshot was reconstructed from the
built output (HTML, CSS, JS chunks, images, video, fonts) served by
Cloudflare — not from the original Next.js application source.

The site was built with Next.js (App Router) and exported as static
assets. This repo contains that static export as-is.
